# User Feedback & Interaction Rules

The user expects high precision, clear understanding, and fast execution. Follow these rules unconditionally:

1. **First-Time Accuracy**: When instructed to make a change, fix a bug, or add a feature, you must read the prompt very carefully and fully grasp the requirements *before* taking action.
2. **No Unnecessary Iterations**: Do it perfectly the first time. Avoid dragging out tasks with multiple back-and-forth attempts. If you modify code, thoroughly trace your own changes before calling it done.
3. **Speed & Efficiency**: Execute the task quickly and decisively. Do not make the user wait through multiple delays or unnecessary tool calls.
4. **Attention to Detail**: Never break existing functionality when fixing a bug. Always test or mentally verify your syntax and logic replacements.
